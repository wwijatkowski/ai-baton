# habits

## About the project
A command-line habit tracker (Python 3, standard library only). Package `habits/`: `models.py` (Habit),
`storage.py` (JSON file), `scheduler.py` (which habits are due), `streaks.py` (streaks, completion), `export.py`
(CSV), `cli.py` (commands). Tests: `python3 -m unittest discover -s tests`.
